## 3. Летающий враг (Flying Enemy)

### Новые файлы:

**Модель:**
- `src/objects/flying_enemy.hpp`
- `src/objects/flying_enemy.cpp`

**UI (Консоль):**
- `src/ui/console/ui_objects/console_flying_enemy.hpp`
- `src/ui/console/ui_objects/console_flying_enemy.cpp`

### Характеристики:

- **Символ в консоли:** `F`
- **Горизонтальная скорость:** 0.2
- **Вертикальная скорость:** 0.15
- **Диапазон полёта:** 10 единиц вверх/вниз от начальной позиции

### Поведение:

1. **Вертикальное движение:**
   - Летает вверх и вниз в заданном диапазоне
   - При достижении границы меняет направление

2. **Горизонтальное движение:**
   - Постоянная скорость
   - Разворот при столкновении с препятствием

3. **Столкновение с Марио:**
   - Убивает Марио при любом касании
   - Не может быть убит прыжком сверху (опасный враг!)

### Технические детали:

```cpp
class FlyingEnemy : public RectMapMovableAdapter,
                    public Movable,
                    public Collisionable
```

- Использует множественное наследование
- Переопределяет `move_vertically()` для специального поведения
- Не реагирует на вертикальные столкновения (летает сквозь платформы)

**Местоположение:** `/home/runner/work/super_mario/super_mario/src/objects/flying_enemy.cpp`

## 4. Прыгающий враг (Jumping Enemy)

### Новые файлы:

**Модель:**
- `src/objects/jumping_enemy.hpp`
- `src/objects/jumping_enemy.cpp`

**UI (Консоль):**
- `src/ui/console/ui_objects/console_jumping_enemy.hpp`
- `src/ui/console/ui_objects/console_jumping_enemy.cpp`

### Характеристики:

- **Символ в консоли:** `J`
- **Горизонтальная скорость:** 0.15
- **Интервал прыжков:** каждые 50 тиков
- **Использует физику:** гравитация и прыжки

### Поведение:

1. **Прыжки:**
   - Автоматический прыжок каждые 50 тиков
   - Использует встроенный метод `jump()` из класса `Movable`

2. **Физика:**
   - Применяется гравитация при падении
   - Реалистичная траектория прыжка

3. **Столкновение с Марио:**
   - Если Марио падает сверху - враг умирает
   - Иначе Марио умирает
   - Аналогично обычному врагу

4. **Проверка края платформы:**
   - Не падает с платформы
   - Разворачивается на краю

### Технические детали:

```cpp
class JumpingEnemy : public RectMapMovableAdapter,
                     public Movable,
                     public Collisionable
```

- Использует счётчик `jump_counter` для управления прыжками
- Переопределяет `move_vertically()` для добавления логики прыжков
- Применяет константы гравитации из базового класса

**Местоположение:** `/home/runner/work/super_mario/super_mario/src/objects/jumping_enemy.cpp`

## Архитектура и паттерны проектирования

### 1. Разделение ответственности

```
Model (Логика)          UI (Представление)
├── Enemy               ├── ConsoleEnemy
├── FlyingEnemy         ├── ConsoleFlyingEnemy
├── JumpingEnemy        └── ConsoleJumpingEnemy
```

- Логика независима от визуализации
- Легко добавить графический UI без изменения логики

### 2. Factory Pattern (Фабрика)

```
UIFactory (абстрактная)
    ↓
ConsoleUIFactory (конкретная)
    ↓ создаёт
ConsoleEnemy, ConsoleFlyingEnemy, etc.
```

- Централизованное создание объектов
- Легко расширять новыми типами

### 3. Template Method Pattern

```
GameLevel (абстрактный)
    ├── init_data() - абстрактный метод
    ├── FirstLevel::init_data()
    ├── SecondLevel::init_data()
    └── ThirdLevel::init_data()
```

- Общая структура уровня
- Специфическая реализация в подклассах

### 4. Множественное наследование

```
FlyingEnemy
    ├── RectMapMovableAdapter (позиция и адаптация карты)
    ├── Movable (движение)
    └── Collisionable (коллизии)
```

- Комбинация нескольких интерфейсов
- Виртуальное наследование решает diamond problem

## Теория C++ на примере реализации

### 1. Виртуальные функции и полиморфизм

```cpp
// Базовый класс
virtual void move_vertically() noexcept;

// Переопределение в FlyingEnemy
void FlyingEnemy::move_vertically() noexcept override {
    // Специфическое поведение полёта
}
```

### 2. Множественное наследование

```cpp
class FlyingEnemy : public RectMapMovableAdapter,
                    public Movable,
                    public Collisionable
```

Враг получает функциональность сразу от трёх базовых классов.

### 3. Виртуальное наследование

```cpp
class Movable : virtual public Rect
```

Решает проблему дублирования при множественном наследовании.

### 4. Абстрактные классы

```cpp
class GameLevel {
    virtual void init_data() = 0;  // Чисто виртуальная функция
};
```

Определяет интерфейс, который должны реализовать подклассы.

### 5. Инкапсуляция

```cpp
private:
    float initial_y;    // Скрыто от внешнего доступа
public:
    void move_vertically();  // Публичный интерфейс
```

### 6. Константность

```cpp
Rect get_rect() const noexcept;
```

- `const` - метод не изменяет объект
- `noexcept` - метод не бросает исключения
