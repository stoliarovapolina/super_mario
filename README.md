Это ООП версия игры Супер Марио, которая:
1. Делает логику независимой от визуального представления.
2. Делает логику независимой от ОС.
3. Логика работает не с множествами объектов, а с множествами абстракций.

## Поддерживаемые платформы

- **Windows** - использует Windows API
- **macOS** - использует Unix/POSIX API (см. BUILD_MACOS.md)
- **Linux** - использует Unix/POSIX API

## Сборка

### Windows
```
build.bat
```

### macOS / Linux
```bash
./build_macos.sh
# или вручную:
mkdir build && cd build && cmake ../src && make
```

Подробную инструкцию для macOS см. в файле **BUILD_MACOS.md**.
